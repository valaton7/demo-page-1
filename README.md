# Norrland Service Group – Demo Page

Static clone of [norrlandsg.se](https://www.norrlandsg.se/) built with Astro for GitHub Pages.

## Development

```bash
npm install
npm run dev
```

## Tests

```bash
npm test
```

## Build

```bash
npm run build
npm run preview
```

## Deployment

Pushes to `main` deploy automatically via GitHub Actions to:

https://valaton7.github.io/demo-page-1/
